# 🏢 Система Управления Общежитием + Telegram Бот Дежурств (PROD)

Полноценное веб-приложение для наглядного визуального расселения студентов общежития (14 комнат на этаже), управления жильцами (CRUD), выгрузки отчетов в Excel и автоматизированного графика дежурств по кухне с интерактивным Telegram-ботом.

---

## 🌟 Основные Функции

1. **Визуальная Карта Общежития (SPA Frontend):**
   - **2 Этаж:** 14 комнат (Женский блок).
   - **7 Этаж:** 14 комнат (Мужской блок).
   - Индикаторы заполняемости: комнаты 1–12 (по 4 койко-места), комнаты 13–14 (по 6 койко-мест).
   - Интерактивный поиск по ФИО, никнейму или номеру комнаты.
   - Сводные KPI карточки (Всего жильцов, Свободные места, 14 дней, В очереди).

2. **Админ-Панель Управления Жильцами:**
   - Заселение новых студентов с выбором комнаты и пола.
   - Изменение данных и переселение жильцов.
   - Выселение со сбросом койко-места и записью в лог.
   - Журнал аудита всех действий.

3. **График Дежурств по Кухне (7 Этаж):**
   - **Авто-ротация:** Каждый день новая заселенная комната по очереди. Пустые комнаты (0 жильцов) автоматически пропускаются.
   - **Интерактивный Календарь:** Просмотр дежурных комнат и имеющихся студентов на каждый день месяца.
   - Отметка «Выполнено ✅» в 1 клик и ручное переназначение.

4. **Интеграция с Telegram-Ботом (`telegram_bot.py`):**
   - Ежедневная рассылка в Telegram-группу в 09:00 с указанием дежурной комнаты.
   - Инлайн-кнопка `[ ✅ Мы выполнили дежурство! ]` — при нажатии в группе статус дежурства **моментально обновляется на веб-сайте** и в базе данных SQLite!

5. **Автоматический Экспорт в Excel (`excel_sync.py`):**
   - Отдельный лист `Карта Расселения` (визуальные карточки).
   - Отдельный лист `Полный Список Жильцов` (таблица всех проживающих).
   - Отдельный лист `График Дежурств` (календарная статистика на месяц).
   - Прямой скачиваемый HTTP-поток в браузер без блокировки файлов на ПК.

---

## 🚀 Быстрый Запуск Проекта

### 1. Запуск Веб-Сервера:
```bash
cd dormitory_app
python server.py
```
Откройте браузер по адресу: **http://localhost:8080**

### 2. Запуск Telegram-Бота:
```bash
python telegram_bot.py ВАШ_ТОКЕН_ОТ_BOTFATHER
```
Добавьте бота в Telegram-группу и отправьте команду `/setgroup`.

## 🛠️ Технологический Стек

- **Backend:** Python 3 (стандартные библиотеки `http.server`, `sqlite3`, `json`, `urllib`).
- **Database:** SQLite 3 (`dormitory.db`).
- **Frontend:** Vanilla HTML5, Modern CSS Glassmorphic UI, Vanilla JS (ES6+).
- **Excel Sync:** OpenPyXL.
